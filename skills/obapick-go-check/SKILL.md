# Goの変更に合う検査を行う

このスキルは、AIが**Goコードの修正と検査**を依頼されたときに使います。

## AIが行うこと

1. 変更するパッケージと関連するテスト、最寄りの \`go.mod\`、対象のGoのバージョンを確認する。
2. コードを変更する前に既存のテストと規則を確認する。無関係なパッケージを一律に読み込まない。
3. 必要な処理だけ修正し、変更したGoファイルの整形を \`gofmt\` で確認する。
4. 変更したパッケージに対応する \`go test\` を実行する。共有部分を変えた場合や影響が不明な場合は、**適切なモジュールのルート**から \`go test ./...\` などへ範囲を広げる。
5. 配布や実行形式に関係する場合は、必要なビルド・起動確認も行う。
6. 実際の検査結果、変更箇所、未確認の範囲を報告する。

## 境界

- 新しい依存の取得、環境の変更、外部公開を無断で行わない。
- \`go test ./...\` をリポジトリのルートで無条件に実行せず、\`go.mod\` の場所と検査対象を確認する。
- テストが0件なら、変更の正しさを確認したと報告しない。コメントは対象の規則を尊重する。
