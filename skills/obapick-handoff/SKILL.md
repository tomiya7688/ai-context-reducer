# 作業を安全に中断して引き継ぐ

このスキルは、AIが**途中中断・担当変更・別チャットへの引継ぎ**を頼まれたときに使います。

## AIが行うこと

1. 使用率の実測値を取得できるなら確認する。取得できない場合は「未計測」とし、数字を作らない。
2. 上限に近い、または次の工程に必要な余裕がない場合、新しい大きな作業を始めず安全な区切りで止める。
3. 作業ツリーの変更、保存済みコミット、未実行の検査、ほかの人の変更の有無を確認する。
4. 未保存の変更がある場合、次の担当が取得できる場所に安全に保存する。コミット・送信は許可された範囲だけとし、秘密情報を含めない。保存できないならその事実を伝えて止まる。
5. 次の内容だけを短く報告する。

```text
目的:
保存先: Issue、ブランチ、コミット、共有差分の場所
完了したこと:
根拠: 仕様・コード・テストの場所と対象の版
確認: 実行した検査と結果。未実行なら未実行
未完了・未確認:
次に最初にすること:
```

## 再開するとき

引継ぎを受けたAIは、未保存の差分を確認・保全してから最新の共有内容を取得し、原典と検査結果を読み直して再開する。会話全文や大量のログは貼り直さない。

**自動的にプロセスを強制終了したり、未検証の変更を完了扱いしたりしない。**
