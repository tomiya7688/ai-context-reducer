# 変更差分を根拠とともに確認する

このスキルは、AIが**コードレビュー**を依頼されたときに使います。

## AIが行うこと

1. 対象の差分、変更の目的、適用する規則、関連テストを確認する。
2. 変更された行から必要な周辺コードを読む。無関係な全ファイルを一律に確認しない。
3. 動作・境界条件・失敗時の扱い・互換性・安全上の問題を、具体的な再現条件とともに探す。
4. 指摘ごとにファイルと位置、問題が起きる条件、根拠、必要な確認を示す。
5. 実際に実行できた検査の結果と、実行できなかった検査を分けて報告する。

## 境界

- 見た目の好みと実際の不具合を混同しない。確認できない問題を断定しない。
- レビューだけならコードを編集・マージしない。指摘がない場合も確認範囲を示す。
- 正しさに必要なテストを、重いという理由だけで省略しない。
