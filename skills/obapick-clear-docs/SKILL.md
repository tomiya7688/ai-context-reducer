# 読者が迷わない説明を書く

このスキルは、AIが**利用者向けの文章**を作成・修正するときに使います。

## AIが行うこと

1. 読者の前提知識と、読み終えた後にできることを決める。
2. ObaPickなどの使い方を読む人に対しては「あなたは～してください」「あなたは～できます」と書く。
3. 一般論なら「読者は」、読者の開発チームなら「開発者は」と書く。読者が作るアプリを使う人は「あなたのアプリの利用者」と明記し、単に「利用者」と呼ばない。
4. AIに任せる仕事は「AIに～させます」、プログラムの処理は「補助ツールは指定した～を調べて～を返します」と区別する。誰が操作・確認するか明確にする。
5. 初めて出る専門用語は、**その言葉を使わずに、具体例や実際の動作から説明**する。理由のない英語名や抽象的な言い換えを並べない。
6. コマンドや依頼文は、読者が端末で実行するものか、AIに渡す文章かを明示する。
7. 元の仕様や実際の動作と照らし、文章で約束したことが事実か確認する。

## 境界

文章を直すためだけにプログラムの機能やコマンド名を変更しない。開発チームの内部都合は、読者の作業に必要な場合を除いて使い方の説明へ混ぜない。
