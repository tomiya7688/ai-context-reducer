# Pythonの変更に合う検査を行う

このスキルは、AIが**Pythonコードの修正と検査**を依頼されたときに使います。

## AIが行うこと

1. 変更するファイルと関連テスト、\`pyproject.toml\`・\`pytest.ini\` など、対象に関係する設定を確認する。
2. プロジェクトのPythonバージョン、依存環境、既存のテスト方法を尊重する。別の道具を勝手に導入しない。
3. 修正する処理の入力、戻り値、失敗条件を確かめ、対象に合う既存テストを先に実行する。
4. \`unittest\` を使うプロジェクトでは関連する \`python -m unittest\`、\`pytest\` を使うプロジェクトでは関連する \`python -m pytest\` を検討する。**利用可能な環境と既存の実行手順を確認してから**実行する。
5. 共有部分へ影響する変更なら、必要に応じて検査範囲を広げる。
6. 実行したコマンド、テストの件数と結果、未実行の検査を報告する。

## 境界

- 依存のインストール、環境の書換え、公開は許可なく行わない。
- 構文が正しいだけで動作の検査を省略しない。テスト0件を成功扱いしない。
- コメントは対象のリポジトリにある規則を優先し、実装に関係する理由と条件を説明する。
