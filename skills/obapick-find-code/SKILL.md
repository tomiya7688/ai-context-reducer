# 作業に必要なコードだけを探す

このスキルは、AIが**コードを変更する前の調査**を頼まれたときに使います。

## AIが行うこと

1. 依頼から目的、対象の機能、完了条件を確かめる。不明点が結果に影響する場合は質問する。
2. 既存の検索機能でファイル名や識別子を探し、候補のパスを出す。最初からリポジトリの全ファイルを読まない。
3. 候補から関係するコード、呼出し先、仕様、テストを**必要な範囲だけ**読む。関係が判明した部分だけ調査を広げる。
4. 対象と必要なテストを特定できたら検索を止める。判断に足りない場合は、次に調べる理由を示す。
5. 候補のパス、具体的な根拠、調査済みの範囲、未確認の範囲を短く返す。

## 境界

- 調査だけを依頼された場合は、ファイルを編集しない。
- 見つけた候補を原因と断定しない。確認できない事実を推測で埋めない。
- AIがファイルを開けない場合は、必要なファイルの場所を伝え、読める情報だけから判断する。
