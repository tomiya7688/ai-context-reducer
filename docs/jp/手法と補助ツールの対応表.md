# 手法と補助ツールの対応表

手法は、専用ツールがなくても実践できます。繰り返し使う手順を自動化したい場合は、ここから目的に合う補助ツールを選べます。先に手法の説明を読み、手作業やプロジェクトに既にある仕組みで足りるなら、ツールを追加する必要はありません。

この表にあるツールもすべて任意です。コマンド、入力、出力、動作条件は各ツールのREADMEに記載し、手法の説明には含めません。

## 使い方

先に手法の説明から、今回の困りごとと必要な結果を決めます。表で対応するツールがあればREADMEを開き、利用可能なときだけ実行します。AIには全出力ではなく必要な候補を渡し、元コードやテストで確かめさせます。ツールの有無だけでは、コンテキスト削減の成否は決まりません。

> 今回は「[作業内容]」を調べます。この手法を補助するツールを選べる場合は実行し、関係する候補と理由だけ示してください。選んだ原典とテストを確認し、結果と未確認範囲を報告してください。

## 用語

表中の「補助ツール」は任意の機械的支援です。人が作業手順を決め、AIへ渡す参照先や結果を絞る流れは **tool-assisted Context Routing** と呼べます。
