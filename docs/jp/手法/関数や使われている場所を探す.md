# 関数や使われている場所を探す

大きなプログラムから、変更に関係する処理や、その処理を使う場所を探す例を紹介します。以下のファイル名と関数名は説明用です。

## 例：設定ファイルがないときの動作を変える

架空の設定アプリで、設定ファイルがない場合に初期設定を使うよう変更するとします。一覧を調べると、次の場所が見つかりました。

```text
設定を読み込む処理: load_settings
その処理があるファイル: src/settings.py
その処理を使う場所: app.py
動作を確かめるファイル: tests/test_settings.py
```

この結果から、次の順で確認できます。

1. `src/settings.py` を開き、設定ファイルがない場合に今どう動くかを見る。
2. `app.py` を開き、読み込んだ設定をどこで使っているかを見る。
3. `tests/test_settings.py` を開き、現在の動作と変更後に確認すべきことを見る。

この3か所を見れば、まず変更方法を考えられます。設定画面や関係のないライブラリを、最初から読む必要はありません。調べている途中で別のファイルも関係すると分かった場合は、そのファイルを追加で確認します。

## いつ使うか

関係する場所を探すのに時間がかかる、大きなプログラムで役立ちます。変更する場所と確認方法がすでに分かっている小さな作業なら、普通のファイル検索で十分です。

## 一覧だけで決めない

この一覧は古くなったり、処理のつながりが抜けたりすることがあります。

## AIへの指示例

```text
変更する処理の名前を検索し、その処理がある場所、使っている場所、関連テストを一覧で確認してください。
一覧に表示されたコードとテストを実際に開き、一覧と現在の内容が一致しているか確かめてください。
一覧にない関係が見つかった場合は、読む範囲とテストを追加してください。
```

## なぜ読む量が減るのか

一覧をAIに渡すと、関係する処理やそれを使う場所を探し始める手掛かりになります。全ファイルを開いて、処理のつながりを推測する手間を減らせます。

## 用語

関数は、名前を付けて別の場所から呼び出せる処理です。

## 補助ツール

- 必要なら、[関数やファイルのつながりを一覧にする補助ツール](../../../tools/common/large/source-structure-index/README.md)を使えます。関係する処理を探す手掛かりになりますが、一覧だけで原因や影響範囲を決めず、コードとテストも確認してください。

すでに使っている検索手段でも同じ場所を探せるなら、それを使えます。
