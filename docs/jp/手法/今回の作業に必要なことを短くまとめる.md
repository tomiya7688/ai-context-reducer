# 今回の作業に必要なことを短くまとめる

数日にわたる作業を別の人やAIに引き継ぐときは、「何を直すか」「どこを読むか」「どうなれば終わりか」を短いメモにまとめます。たとえば表データの日付が1日ずれる不具合なら、日付を読むコードと関連テストを示し、AIに修正後の表示を確認させると書きます。

このメモには、今回の作業を進めるために必要なことを書きます。詳しい仕様や決定を丸ごと写す場所ではありません。

## メモに書くこと

```text
今回すること:
  表データの日付が1日ずれる不具合を直す

最初に見る場所:
  日付を読むコード、関連するテスト、日付の決まり

守ること:
  ほかの日付や保存済みデータの動きを変えない

終わりの目安:
  同じ入力で正しい日付が表示され、関連テストも通る

今回はしないこと:
  表データ全体の作り直し

詳しい説明:
  日付の仕様書や作業依頼へのリンク
```

作業に関係する資料が増えたら、必要なものだけ追加します。長い仕様、コード全文、ログをそのまま貼る必要はありません。詳しい依頼条件はIssueや作業依頼から、決定済みの仕様は設計文書から、現在の動きはコードやテストから確認できるよう、それぞれの場所を書きます。

## 詳しい資料との使い分け

| 情報 | 書く場所 |
| --- | --- |
| 今回の目的、最初に読む場所、守る条件、終わりの目安 | 今回の作業メモ |
| 長く有効な仕様や決定 | 説明書や設計資料 |
| 作業依頼や未完了の項目 | 依頼文や未完了作業の一覧 |
| 実際の動き | プログラムとテスト |

参照先は情報の種類で変わります。今回頼まれた作業と完了条件はIssueや作業依頼、決定済みの仕様は設計文書、現在の動きはソースコードとテストで確認します。作業メモには、それぞれの参照先を分けて記載します。

メモと参照先の内容が違う場合は、どちらが古いかを決めつけず、作業依頼・設計文書・コードやテストを照らし合わせます。仕様と実際の動きが食い違っていて、どちらに合わせるか判断できないときは、推測で変更せず確認します。

## 作業が終わったら片づける

今回限りの情報を次の作業にそのまま持ち越しません。今後も必要な決定や未完了の項目は、説明書や作業記録へ残し、メモから参照できるようにします。メモが長くなったら、今回必要な情報だけを残します。

## 項目は必要な分だけ使う

すべての作業で同じ項目を埋める必要はありません。小さな修正なら、目的と確認方法だけで十分なことがあります。複数日にわたる作業や、別の人への引き継ぎでは、守る条件や今回はしないことも書くと行き違いを防げます。

## AIに渡すとき

複数日にまたがる作業では、[作業メモのひな型](../../../templates/CONTEXT_PACK.md)をリポジトリ直下へ `CONTEXT_PACK.md` という名前でコピーし、必要な項目を埋めます。次のAIへの依頼に「`CONTEXT_PACK.md` を先に読んでください」と書き、ファイルの場所を指定します。AIが別の作業フォルダーを使う場合は、そのフォルダーへ置いて実際のパスを伝えてください。今回だけの短い条件なら、別ファイルを作らず依頼文に直接書きます。

会話に貼る場合も、長い資料は貼らず、必要な条件と、設計文書・Issue・コード・テストのうち今回確認するものの場所をAIに伝えます。

```text
次の作業メモを読んで、目的、最初に見る場所、完了の目安を確認してから作業してください。
依頼内容はIssueや作業依頼を、決定済みの仕様はリンクされた設計文書を確認してください。現在の動きはソースコードとテストで確かめてください。
メモにない条件を推測で決めず、不明な点は質問してください。
```

## なぜ読む量が減るのか

短いメモをAIに渡せば、会話や過去の履歴を探させずに、作業の目的と読む場所を伝えられます。詳しい依頼条件はIssueや作業依頼、仕様は設計文書、実際の動きはコードやテストから必要なものだけ確認させるため、長い内容を毎回メモへコピーする必要はありません。

## 用語

- **作業用メモ**: 今回の目的、読む場所、守る条件、確認方法を短くまとめたメモです。
- **Context Pack（作業用メモ）**: いま進める作業の目的・対象・守る条件・完了の判断方法を、着手時に読める短いメモにしたものです。必要な項目だけ残す[作業メモのひな型](../../../templates/CONTEXT_PACK.md)から作れます。

## 補助ツール

- 必要なら、[`context-pack-builder`](../../../tools/common/medium/context-pack-builder/README.md)が依頼資料から、目的・参照先・完了条件をまとめた作業メモの草案を作ります。内容は原典と照らして確認してください。
