# 困りごとから手法を探す

このページは、AIに作業を頼む人が、自分の困りごとに合う説明を探すための目次です。全部の方法を取り入れる必要はありません。困っていることに近い項目を一つ選んでください。

ここで選んだ説明は、利用者が案内や一覧を用意し、作業を頼むときにAIへその場所と使い方を伝えて使います。AIが自動で文書を読むとは限りません。継続して使う場合は、使っているAIが読む指示書や設定に登録されているか確かめてください。

「複数ファイルの出力が後半だけ粗くなる」「どのモデルや編集方法を選べばよいか」など、具体的な質問から短い依頼例を探す場合は、[AI利用でよくある質問](../AI利用/よくある質問.md)を先に見てください。

## 初めて読む場合

作業ごとにどのくらい情報を渡すか迷う場合は、[作業ごとのコンテキスト使用量の目安を作る](../AI利用/作業ごとのコンテキスト使用量の目安を作る.md)で、一回の入力と作業全体の量を分けて記録する方法を確認できます。

まず[AIに作業を頼むときの基本手順](AIに作業を頼むときの基本手順.md)で、一つの作業を進める流れを確認してください。読む量を減らす考え方は[AIに読む情報を絞る3つの方法](AIに読む情報を絞る3つの方法.md)、導入する方法の選び方は[必要な方法だけ選ぶ](../導入/必要な方法だけ選ぶ.md)を参照してください。

LLMのしくみから理解したい場合は、[LLMとは何か](../LLMの仕組み/LLMとは何か.md)から順に読めます。AIの種類や選び方は[コーディングエージェントの種類と選び方](../AI利用/コーディングエージェントの種類と選び方.md)にあります。

## 選んだ方法をAIに使わせ、効果を確かめる

単発の作業では、依頼文に「どの案内を使うか」「最初に何を返すか」「どこまで確認するか」を書きます。繰り返す作業では、その案内へのリンクと適用範囲を、AIが実際に読む指示書に置きます。

完了時には、参照したファイル、実行した確認と結果、未確認の範囲を報告させ、表示される作業履歴や差分と照らします。読み込み履歴が見えない環境では、報告だけで実際のコンテキスト量は分かりません。その場合は、案内が正しい原典へ導いたことと、必要なテストを省いていないことを確認します。トークン数を測れるツールがある場合だけ、同じ種類の作業で導入前後を比べてください。

```text
今回の作業：[作業内容]
「[選んだ手法のページ]」を使ってください。最初に確認候補と選んだ理由を示し、候補の原典を確認して作業してください。
完了条件に必要な確認を実行し、参照先・結果・未確認範囲を報告してください。
```

補助ツールは必須ではありません。使いたい場合は[手法と補助ツールの対応表](手法と補助ツールの対応表.md)から選んでください。

## AIへの指示書を増やしすぎない

まずは、AIに守ってほしい決まりと詳しい資料の場所を書いた短い指示書を一つ置きます。別の場所だけに当てはまる決まりまで読ませてしまうことが続く場合に限り、その場所用の指示書を追加します。何度も使う手順は再利用できる形にし、一度だけの手順は依頼文に書きます。共通の決まりは一か所に置き、詳しい説明へリンクし、古い例は削除します。AI製品ごとに指示書や再利用手順の読み込み方が違うため、必要なら場所や呼び出し方を依頼文で伝えてください。
