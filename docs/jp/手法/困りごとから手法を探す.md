# 困りごとから手法を探す

AIにコードの修正や調査を頼むとき、**あなたは今困っていることに近い項目を下の一覧から選んでください。** リンク先では、AIに何を頼み、何を確認すればよいかを具体例とともに説明しています。すべての方法を順番に使う必要はありません。

あなたが選んだ方法をAIに使わせたい場合は、そのページの場所と今回の作業内容をAIへ伝えてください。AIが自動でそのページを読むとは限りません。AIがファイルを開けない環境なら、必要な説明をあなたが渡してください。

例えば「回答の後半だけ内容が雑になる」「どのAIモデルを選ぶか分からない」という場合は、先に[AI利用でよくある質問](../AI利用/よくある質問.md)で近い質問を探せます。

## 初めて読む場合

初めてAIにコードの修正を頼むなら、あなたは[AIに作業を頼むときの基本手順](AIに作業を頼むときの基本手順.md)から読んでください。AIに渡す情報を選ぶ方法は[AIに読む情報を絞る3つの方法](AIに読む情報を絞る3つの方法.md)、取り入れる方法の優先順は[必要な方法だけ選ぶ](../導入/必要な方法だけ選ぶ.md)で説明しています。

LLMの仕組みを知りたいなら[LLMとは何か](../LLMの仕組み/LLMとは何か.md)、コーディングエージェントを選びたいなら[コーディングエージェントの種類と選び方](../AI利用/コーディングエージェントの種類と選び方.md)を読めます。作業ごとの使用量を記録する場合は[作業ごとのコンテキスト使用量の目安を作る](../AI利用/作業ごとのコンテキスト使用量の目安を作る.md)を参照してください。

## 選んだ方法をAIに使わせる

あなたは今回の作業内容と、選んだページの場所をAIに伝えてください。AIがページを開けるなら、AIに必要な箇所を読ませます。ファイルを開けないAIを使う場合は、あなたが関係する説明を貼り付けてください。

**次は、あなたがAIに送る依頼文の例です。**

```text
今回の作業：[作業内容]
「[選んだ手法のページ]」にある方法を使ってください。
最初に確認するコード・仕様・テストの候補と、選んだ理由を教えてください。
元の資料を確かめてから作業し、変更差分・実行した検査・結果・未確認の範囲を報告してください。
```

AIが作業を終えたら、**あなたは変更差分と実際の検査結果を確認してください。** AIが「確認済み」と書いただけでは、元のコードやテストを読んだ証拠にはなりません。使用量を計測できる環境なら、必要な根拠を省かず、同じ条件でAIへの入力量を比べられます。

特別な補助ツールを入れずに始めても構いません。必要なときは[手法と補助ツールの対応表](手法と補助ツールの対応表.md)から、あなたやAIが使える道具を探せます。

## AIへの指示書を増やしすぎない

あなたが同じ決まりを毎回AIに伝えている場合は、AIが実際に読む指示書に共通の決まりと資料の場所を書けます。特定のフォルダーだけに必要な決まりは、そこで作業するときだけ読ませてください。AI製品によって指示書の読み方は違うため、あなたが利用するAIの設定を確認し、必要なら依頼文で場所を伝えてください。
