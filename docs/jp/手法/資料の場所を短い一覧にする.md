# 資料の場所を短い一覧にする

ファイルや説明書が多い架空のアプリで、AIに「表データの日付が1日ずれる不具合を直して」と頼む場面を考えます。AIに全ファイルを読ませる代わりに、日付の決まり、日付を処理するコード、関連テストの場所を一覧で知らせます。

| 資料の場所 | 何が分かるか |
| --- | --- |
| `docs/date-format.md` | 日付の決まり |
| `src/data/date.py` | 日付を読み書きする処理 |
| `tests/data/test_date.py` | 日付処理の確認方法 |

一覧をAIに渡すと、今回必要な資料を選んで開かせられます。全ファイルを順番に読ませる必要はありません。

## 一覧には場所と用途だけを書く

一覧に載せるのは、必要な資料を見つけるための情報です。

- ファイル名、フォルダー名、URLなどの場所
- その資料で何が分かるか
- どの機能や作業に関係するか
- 必要なら、古い・生成済みなどの注意

説明書やコードの本文、長い要約、差分、ログは一覧へ写しません。詳しい内容が必要になったら、一覧にある場所から元の資料を開きます。

## ほかの文書との使い分け

同じ内容を複数の文書に書かないよう、文書ごとの役割を分けます。

| 文書 | 何を書くか |
| --- | --- |
| プロジェクト全体の指示書 | AIに最初に読ませる資料、全体で守る決まり |
| [プロジェクトでできることと制限を短くまとめる](プロジェクトでできることと制限を短くまとめる.md) | 今使える機能、制限、まだ使えない機能 |
| この一覧 | 詳しい資料がどこにあるか |
| [今回の作業に必要なことを短くまとめる](今回の作業に必要なことを短くまとめる.md) | 今回の目的、AIに読ませる資料、守る条件 |
| 説明書・作業依頼・コード・テスト | 詳しい仕様、決定、実際の動き |

一覧と説明書の内容が食い違ったら、一覧に記された説明書を開いて確認します。作業依頼で決まったことはその依頼を、実際の動きはコードやテストを確認します。

## AIには関係する資料だけ渡す

一覧の項目が増えすぎたら、今の作業に関係する項目だけをAIに見せます。たとえば日付の修正なら、日付の決まり、処理、テストの項目から確認を始めます。

一覧に載っているからといって、すべて開く必要はありません。どの資料を読むかは、今回の作業内容に合わせて決めます。一覧にない資料が必要だと分かったら、その資料も追加で探します。

## 作ると役立つ場合

同じファイルや説明書を何度も探し直しているなら、資料の場所と用途をまとめた一覧を作ると、次回から見つけやすくなります。作業ごとに読む資料が変わり、プロジェクト全体を見回さないと必要な資料を特定できない場合にも役立ちます。

依頼に必要なファイルが書かれている、小さなプロジェクトで探す場所がすぐ分かる、一度きりの作業といった場合は作りません。既存の目次や指示書で十分なら、それを使います。

## どこに保存し、AIにどう読ませるか

繰り返し使う一覧は、たとえば `docs/AI資料一覧.md` という名前で保存します。リポジトリ直下の `AGENTS.md` に「作業内容に関係する資料を探すときは `docs/AI資料一覧.md` を参照」と書き、AIが使う入口からリンクします。AIが `AGENTS.md` を自動で読まない場合は、依頼文で `docs/AI資料一覧.md` の場所を伝えてください。一度だけの作業なら一覧を新設せず、今回読む資料を依頼文に書きます。

## 内容が変わったら更新する

ファイルの移動や役割の変更があったら、一覧も直します。古い一覧は誤った場所を示すので、正しいか分からない項目は使わず、実際のファイルを検索します。詳しい説明を一覧に書き足さず、元の説明書を更新します。

## 表の形式は自由

文書内の表や、すでにあるプロジェクトの一覧で構いません。場所と用途を記載して、その一覧をAIに渡してください。必要なら、AIに詳しい説明も開かせます。

## AIへの指示例

```text
作業内容に関係する行だけを一覧から選んでください。
その行に書かれた資料を開き、必要な内容を確認してください。
一覧に必要な資料が見つからない、または内容が古い場合は検索して追加してください。
```

## なぜ読む量が減るのか

一覧に資料の場所と用途をまとめておけば、AIは全ファイルを順番に開かず、作業に関係する資料から読めます。

## 補助ツール

- 必要なら、`context-manifest`がファイル名や大きさなどを一覧にします。読む候補の場所を探すときに使えます。何を読むかは一覧を渡し、AIに作業との関係から選ばせてください。

手作りの一覧や、プロジェクトで使っている検索機能でも同じ目的を果たせます。
