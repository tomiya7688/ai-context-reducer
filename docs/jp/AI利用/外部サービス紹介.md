# 外部サービス紹介

ObaPickは、AIに渡す情報を必要な範囲へ絞る手法を説明しています。このページでは、その手法に関係する**外部サービスの実例**と、利用する前に確認する条件を紹介します。

**ここに掲載したことは、導入や契約の推奨ではありません。** 有料サービスも技術的な事例として扱います。サービスが使えなくても、リンク先の手法は自分の文書や既存の検索方法で実践できます。

## 共有メモリ：Living Brain

**提供元：ChatAndBuild Limited**  
**公式サイト：[Living Brain](https://livingbrain.com/)**  
**対応する手法：[複数のAIで記憶を共有し、必要な情報だけ読み出す](../手法/複数のAIで記憶を共有し必要な情報だけ読み出す.md)**

Living Brainは、会話や資料から保存した情報を整理し、後のAIの作業で必要な内容を検索・取得できるようにする外部サービスです。あなたが共通の保存先を使い、別々のAIに必要な記憶を取得させる仕組みの具体例です。[1][2]

| 確認項目 | 2026年11月5日に公式資料で確認した内容 |
| --- | --- |
| **何ができるか** | 会話、メモ、リンク、文書などを取り込み、関連情報の検索、ページ単位の読出し、短い索引の取得ができます。[1][2] |
| **AIとの接続** | 公式資料にはChatGPT・Claudeのアカウント認証によるMCP接続と、Claude Code・Codex等の開発用のAPIキーを使う接続が案内されています。各製品の設定や対応機能によって操作できる範囲が異なります。[2] |

| **商用利用** | [利用規約](https://livingbrain.com/terms-of-service)は個人・商用の両方の利用を認めていますが、契約プランと規約の条件に従います。[4] |
| **表示義務** | 確認した利用規約の本文からは、通常の利用であなたの成果物に製品名を表示する必要があるかを明確に判断できませんでした。**表示義務なしと保証するものではありません。** 予定する使い方に応じて最新の規約や提供元へ確認してください。[4] |
| **導入・管理** | 外部アカウントと接続設定が必要です。MCP対応のChatGPT・Claudeではサインインによる接続を案内しています。開発用の接続にはAPIキー等の管理が必要な場合があります。[2] |
| **保存データの扱い** | 外部のサービスへ情報を渡すため、組織の機密情報、アクセス権、データの保持期間や削除方法を確認します。接続解除だけでは、すでに保存されたデータが削除されるとは限りません。[4][5] |

上記の価格は**Living Brain側の処理に関する料金表の表示**です。ChatGPTやClaudeなど、別途利用するAIの契約料金まで含む金額とは限りません。共有メモリを使うときの合計費用は、保存・検索・要約・AIの入出力を合わせて比べてください。

### このサービスで具体化できること

別のAIが作業するたびに会話全文を渡す代わりに、共通の保存先から該当する記憶だけを検索できます。ただし、**保存した情報が正しいか、古くなっていないか、検索で必要な情報が見つかったか**は別に確認する必要があります。

例えば設定ファイルの保存先が変わったという記憶を取得した場合、AIはその記憶だけを根拠にコードを変更せず、現在の仕様・コード・関連テストを確認します。これは共有メモリの一般的な使い方の説明で、Living Brain自体の正答率や削減率の実測結果ではありません。

### このサービスを使わなくてもよい場合

一つの短い作業や、関係するAIが少なく、Gitで管理した作業メモや仕様書を検索するだけで足りる場合は、外部サービスを加える必要はありません。保存・検索のために外部通信や費用、運用管理が増えるなら、それらも含めて判断してください。

## 外部サービスを評価するとき

あなたが別の外部サービスを検討するときも、**提供元と公式資料、できること、料金・無料枠、商用利用、表示義務、導入方法、データの扱い**を確認してください。「無料で使える」と「商用利用できる」は別です。条件が分からない場合は「不明」と明記し、利用できると決めつけません。

AIの作業で得た削減率や品質の改善についても、サービス提供元の公表値と、あなたの仕事で測定した結果を分けてください。ObaPickはこのページでサービスの性能を独自測定していません。
