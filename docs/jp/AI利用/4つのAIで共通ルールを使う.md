# Claude Code・Codex・ChatGPT・Copilotで共通ルールを使う

このリポジトリを複数のAIで扱うとき、同じ規則を四か所に書き写すと、修正漏れや矛盾が生じます。さらに、似た長文を複数の入口から読み込めば、コンテキストも増えます。

**共通の決まりはリポジトリルートの [AGENTS.md](../../../AGENTS.md) を正本として、一か所で編集します。** ツール固有の入口は、正本を参照するためだけに使います。共通ルールには、調査範囲、文書の日英対応、検証、権限、結果報告など、毎回必要な条件だけを書きました。

## 四つの環境へどう渡すか

| 利用環境 | リポジトリ内の入口 | 適用時に確認すること |
| --- | --- | --- |
| **Codex**（CLIなど） | ルートの `AGENTS.md` | 対象リポジトリ内で作業し、該当する指示が読み込まれたか確認する。作業場所や設定によって読込範囲が変わる。 |
| **Claude Code** | `CLAUDE.md` の `@AGENTS.md` | `@AGENTS.md` は本文の読み込みを指定する記法。新しいClaude Codeは `AGENTS.md` に直接対応するが、この入口を残すことで古い版や設定でも正本を共有する。 |
| **GitHub Copilot** | `.github/copilot-instructions.md` と、対応機能では `AGENTS.md` | IDE、クラウドエージェント、コードレビューなどで対応する指示形式が異なる。両方読まれても規則本文を二重に持たないよう、Copilot用は短い案内だけにする。 |
| **ChatGPT** | GitHub連携等でルートの `AGENTS.md` を取得するか、必要なら添付する | 通常のチャットやプロジェクトがリポジトリの `AGENTS.md` を自動読込するとは限らない。プロジェクト指示・依頼文で明示して、アクセス可能か確認する。 |

これは**リポジトリのファイルを配置しただけで四製品へ必ず適用される**という保証ではありません。読み込まれるファイルは製品、機能、バージョン、ユーザー設定によって異なります。とくにCopilotの支援機能ごとの対応を一括して扱いません。詳しくは後述の公式資料で確認します。

## ChatGPTで使うとき

ChatGPTのプロジェクトでは、プロジェクト設定の指示欄に、例えば次を登録します。これは登録例であり、このリポジトリが利用者のChatGPT設定を自動変更するわけではありません。

```text
リポジトリ tomiya7688/ai-context-reducer の作業では、
最初にルートの AGENTS.md を取得し、適用される共通ルールに従ってください。
一度も取得できていない内容を、読んだものとして扱わないでください。
アクセスできない場合はそのことを伝え、必要な本文を提示してもらってください。
今回の作業に必要な原典と完了条件は、別途確認してください。
```

GitHub連携などでリポジトリを読む権限がなければ、指示しただけでは読めません。その場合、利用者は `AGENTS.md` の本文を添付するか、閲覧可能な方法で渡します。会話の途中で作業対象が変わったときも、無関係な過去の資料を引き継ぐ必要はありません。[作業ごとにAIの役割とチャットを分ける](作業ごとにAIの役割とチャットを分ける.md)を参考にしてください。

## 新しいルールを加えるとき

1. **四製品のどれでも守るべき規則か**を判断します。特定ツールでのみ必要な操作なら、そのツールの案内へ短く書きます。
2. 共通事項なら `AGENTS.md` **だけ**を変更します。Claude CodeやCopilot用の入口に同じ段落をコピーしません。ChatGPTのプロジェクト指示も、正本を読む案内のままにします。
3. 詳しい手順が必要なら、既存の[手法一覧](../手法一覧.md)や対応する実装の説明へ分け、毎回読み込む指示を長くしません。
4. 共通ルールが適用されるか、実際に使う各環境で検査します。ファイルを認識したことと、すべての条件を守って作業したことは別なので、小さな読取り専用の依頼で、参照した規則の場所と確認範囲を尋ねます。

## 読み込まれない・二重になるとき

- **Claude Code:** `/context` などでメモリファイルを確認します。 `CLAUDE.md` に `@AGENTS.md` がある場合は、文章で「読んで」と書くだけの案内とは違い、インポートされます。Claude Codeの新しい版は `AGENTS.md` を直接認識しますが、プロジェクトの `CLAUDE.md` がある場合などは読込の優先関係が変わります。[公式説明][claude]で現在の動作を確認してください。
- **Codex:** 作業する場所から適用される `AGENTS.md` の範囲を確認します。ルートの指示が読み込まれたかを作業ログなどで確かめます。
- **Copilot:** 利用するIDEや機能がリポジトリ共通の指示を読み込むか確認します。`.github/copilot-instructions.md` は短い案内なので、`AGENTS.md` を自動で読み込んだ環境に本文を重ねません。
- **ChatGPT:** GitHubのリポジトリに接続していることと、対象ファイルを今回実際に取得したことを分けます。アクセス不可なら、読めたふりをせず、必要な内容を渡してください。

**指示ファイルはAIへの文章であり、アクセス制限や承認設定の代わりではありません。** 必要な許可を与えていない操作は、指示に書いてあっても実行できません。ルールの全文を無関係な仕事へ繰り返し貼り付けるより、今回の目的と必要な参照先を短く指定してください。
