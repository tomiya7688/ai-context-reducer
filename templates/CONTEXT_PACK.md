## Source Excerpts

## Context Priority
- P0: 必須情報
- P1: 現在の変更対象
- P2: 直接依存
- P3: 参考情報
- P4: 履歴・補助情報

## Optional Extensions
プロジェクト固有の情報が必要な場合のみ追加する。

例:
- performance notes
- test scope
- runtime environment
- generated summary
- dependency notes
- project-specific metadata

## Rules
- リポジトリ全体を無条件に含めない。
- 必要な情報だけを入れる。
- 要約だけで判断できない場合は原典を参照する。
- 古い Context Pack を原典として扱わない。
- 作業終了後に長期保存すべき内容は正式な設計文書・Issue・コードへ反映する。
- このテンプレートは拡張可能とし、標準項目を壊さない範囲でプロジェクト固有項目を追加してよい。
