# このプロジェクトでAIが作業するときのルール

このファイルには、多くの作業で守るルールと、詳しい説明の場所を書きます。同じ説明をコピーせず、短く保ってください。

## 作業を始める前に

- 依頼の目的、変えてはいけないこと、完了の目安を確認する。
- 関係するコード、説明、確認方法を検索してから読む。
- プロジェクトの機能や制限が関係する場合は `PROJECT_CONTEXT.md` を確認する。
- 変更するファイルまでのフォルダーに、その場所だけの作業ルールがあれば確認する。

## 作業中

- 依頼された範囲だけを変更する。
- このプロジェクトで既に使われている書き方や道具に合わせる。
- 条件が不明、または説明とコードが食い違う場合は、推測せず確認して報告する。

## 作業を終える前に

- 変更に関係するテストや動作確認を行う。実行していない確認を、済んだことにしない。
- 変更したこと、確かめたこと、未確認のことを報告する。
- 今回の変更で内容が古くなった説明があれば更新する。

## 詳しい説明

- プロジェクト情報: `PROJECT_CONTEXT.md`（機能や制限が関係する作業で読む）
- [ビルドやテストの説明へのリンク]（その確認が必要な作業で読む）
- [特定のフォルダーだけに当てはまるルールへのリンク]（対象フォルダーを変更するときに読む）

リンクの書き方の例:

```markdown
- 機能や制限を確認するときは [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md) を読む。
- 保存処理を変更するときは [保存形式の説明](docs/data-format.md) を読む。
```

プロジェクトに合わない例やリンクは削除し、実際のファイル名と相対パスに置き換えてください。詳しい説明を置くだけでなく、このファイルから「どの作業で読むか」とリンクを示します。使うAIがこの `AGENTS.md` を自動で読むか確かめ、自動で読まない場合は作業依頼でパスを伝えます。特定のフォルダーだけのルールがある場合に限り、そのフォルダーにも `AGENTS.md` を置きます。

繰り返す作業の手順は、使っているAIがSkillsに対応している場合に限り、Skillへ置き、このファイルへ複製しません。Skillを使う条件と呼び出し方法は、実際の作業で確かめてください。
